# Finance Learning Knowledge Base

这是一个持续扩展的个人财务学习知识库。

目标不是单纯保存读书笔记，而是逐步建立一套能够用于**理解公司、分析行业、阅读财报并形成判断**的 Finance Knowledge Base。

## 学习方式

当前以《财报决策力》为主线，通过以下方式学习：

- 阅读书籍与财务资料
- 与 ChatGPT 讨论概念
- 完成 Quiz 并复盘错误
- 用案例连接财务数字与商业活动
- 将长期知识提炼为独立 Concept Notes

## Learning Principle

核心分析思路：

> 财务数字是经营活动的结果。看到数字变化，不急着下结论，而是继续追问：**为什么？**

长期目标：

**Financial Statements → Business Model → Industry Structure → Company Quality → Valuation**
