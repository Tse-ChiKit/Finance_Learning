# 《财报决策力》学习记录

## 学习目标

不是为了学习会计考试知识，而是借助财报逐步获得以下能力：

1. 看懂一家公司如何赚钱。
2. 理解财务数字背后的经营活动。
3. 判断利润质量、现金流与资产负债状况。
4. 学会结合行业和商业模式解释财务差异。
5. 最终通过财报理解公司与行业的发展。

## 学习方式

每天约 40 分钟：

- 阅读书中内容
- 用案例理解概念
- 完成 Quiz
- 记录自己的 Takeaway
- 将长期知识拆分到 `02_Concepts/`
- 将重要认知漏洞记录到 `03_Quiz/mistakes.md`
