# Balance Sheet 资产负债表

## 一句话理解

资产负债表描述公司在**某一个时间点**拥有什么、欠什么，以及最终属于所有者的部分。

## 属于哪张财务报表

本文件本身就是三张核心财务报表之一。

## 核心机制

初学阶段先用三个大类理解：

- Assets 资产：公司拥有或控制的资源
- Liabilities 负债：公司需要承担的义务
- Equity 所有者权益：扣除负债后归属于所有者的部分

后续将学习最重要的恒等式：

```text
Assets = Liabilities + Equity
资产 = 负债 + 所有者权益
```

## 与其他报表的关系

利润表告诉我们“这一段时间赚了多少”，资产负债表则帮助判断公司为了经营这些业务占用了什么资源、承担了什么义务。

例如：

- 客户尚未付款 → 可能形成应收账款（Accounts Receivable）
- 商品尚未卖出 → 可能形成存货（Inventory）
- 欠供应商的钱尚未支付 → 可能形成应付账款（Accounts Payable）

## 为什么重要

两家公司即使净利润相同，为了创造这些利润所需要的资产规模、债务水平和营运资金可能完全不同，因此公司质量也不能只凭利润判断。

## 分析时要问的问题

- 公司主要资产是什么？
- 资产中有多少是现金、应收、存货、固定资产？
- 为了经营，公司借了多少债？
- 某项资产为什么突然增加？
- 资产增长有没有带来相应的收入和利润？

## 常见误区

### 资产越多，公司越好

不一定。大量资产如果不能产生足够收益，反而可能代表经营效率较低。

### 负债一定是坏事

不一定。负债的风险要结合用途、成本、期限和偿还能力判断。
